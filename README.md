# AI Study Coach

A simple web app I built to help organize study routines, track progress, and stick to learning goals without feeling overwhelmed.

---

## What it does

- **Study Schedules:** Helps break down subjects into manageable daily/weekly chunks.
- **Progress Tracker:** Keep track of topics finished and what's left to do.
- **Focus Reminders:** Quick study strategies and reminders to stay on track.
